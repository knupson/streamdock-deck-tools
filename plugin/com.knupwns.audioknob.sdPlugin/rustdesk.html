Paste the ID with or without the spaces RustDesk shows it in — they are taken out either way. With no Name, the tile prints the ID grouped the way RustDesk does.

Turn Label off for the mark on its own, drawn full size — the tile then matches the icon-pack keys rather than leaving a caption's worth of room empty.

NO APP on the tile means the executable is not where RustDesk says it is. Leave that field empty for the usual C:\Program Files\RustDesk\rustdesk.exe; environment variables such as %LOCALAPPDATA% are expanded.

The connection itself is RustDesk's business: this key runs rustdesk.exe --connect <id> and gets out of the way, so the password prompt and any saved credentials are the ones you already have.
