Press opens the session. The tile shows the round-trip time while the machine is accepting SSH on that port and DOWN when it is not — the port itself is dialled rather than pinged, so a machine that answers but has no sshd still reads as down. Intervals are in seconds; turn Watch host off for a plain launch key.

A down host is still dialled when you press: the connection error belongs in the terminal where you can read it.

Custom command is a whole command line, with {host}, {user}, {port} and {target} (user@host) substituted in — that is where an identity file, a jump host or PuTTY goes. Nothing is passed through a shell, so quote a path that contains spaces and nothing else needs escaping.

Host and user may only contain letters, digits, dots, dashes and underscores; anything else is refused rather than put on a command line.
