Tick as many figures as you want on the one key: each gets a row with a bar under it. One on its own instead gets the whole tile — big value and a sparkline of where it has been. Four rows is about as many as stay readable across a desk.

Turn Host name off when the key sits directly above or below an SSH key for the same machine: the name is already there, and the caption costs a whole row.

Pressing reads the machine straight away instead of waiting for the next interval.

Every key pointed at the same machine shares one reading, so four tiles watching one host are one SSH connection every interval, not four. Intervals are in seconds and start at 5: each poll is a full handshake, because the Windows SSH client cannot reuse a connection.

DOWN means the machine did not answer with a reading — unreachable, the key refused, or deckstats not installed. The plugin log says which.

Set the host up first with .\remote\install-deckstats.ps1 -Target user@host, which prints the exact values for the fields above. It authorises a key that can run nothing but the metrics script, so what is sitting on your disk unencrypted is not a way into the machine.
