The tile shows the round-trip time while the machine answers, DOWN when it does not, and WAKE just after a wake packet — during that window it is polled every 3 seconds so you see it come up.

Press wakes it when it is down, and re-checks when it is already up.

Check port at 0 uses ping. Set it to 22 or 3389 for a machine that drops ICMP but serves something — a firewalled host would otherwise always read as asleep. Intervals are in seconds.

Wake-on-LAN has to be enabled in the target's BIOS and network adapter, and the packet only crosses the local network unless the router forwards it.
